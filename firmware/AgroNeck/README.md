# AgroNeckCode

Código del AgroNeck para la ESP32. Incluye librerías para:

- LoRa
- GPS
- MPU6050
- MLX90614
- LM35

## Funcionando:

- Comunicacion con MPU6050(Aceletometro y giroscopo) y MLX90614(Sensor Temp. Interna). 

- Lectura Sensor LM35

- Comunicacion GPS. 

- Comunicacion LoRA.
