# firmware
Este incluye el código que compone a los microcontroladores del AgroNeck y del AgroBot.

---

### Estructura del Proyecto
**AgroNeck/** Código del collar smart en campo que incluye alimentación solar, ubicación, pulso y transmisión de datos.  
**AgroBot/** Código de la estación fija de recepción de datos que incluye la presentación de los mismos en una interfaz en un Display LCD Touch.
